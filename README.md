# Le Fox — Bar à Lyon

Site de présentation façon diaporama (13 slides animées) pour le projet d'ouverture du bar **Le Fox** — *Au fût et à mesure.*

## Utilisation
Ouvrir `index.html` dans un navigateur (aucune installation nécessaire).

- Navigation : flèches ← →, espace, molette, balayage tactile, points en bas
- `F` plein écran · `P` lecture automatique · `#N` dans l'URL pour accéder à une slide

## Fichiers
- `index.html` : contenu des slides
- `style.css` : design, transitions (fondu, glissement, cercle, balayage, montée) et animations
- `app.js` : moteur de slides, compteurs animés
- `assets/devanture.png` : photo de la devanture

> Les chiffres de marché et le prévisionnel sont des **estimations plausibles** (ordres de grandeur lyonnais), à valider par une étude de marché et un expert-comptable.
